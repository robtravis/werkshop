# Werkshop

Blender add-ons for archviz, by [Vivinel](https://www.vivinel.com/).

**Werkbench** · **Mographwerks** · **Motionwerks** (+ Camerawerks) · **Sketchwerks**

> ⚠ **Beta 1.** Expect changes. Blender **5.2** or newer.

## Install

Add the repository once, then install whichever add-ons you want — updates arrive
through Blender from then on.

1. **Edit ▸ Preferences ▸ Get Extensions**
2. **Repositories ▸ + ▸ Add Remote Repository**
3. URL: `https://robtravis.github.io/werkshop/index.json`
4. Name it **Werkshop**, tick **Check for Updates on Startup**, press **Create**
5. The four add-ons appear under Werkshop — install and enable the ones you want

### Sidebar tab order

Blender orders sidebar tabs by the order add-ons are *enabled*, and offers no way for an
add-on to ask for a position. To get **Werkbench · Mographwerks · Motionwerks · Camerawerks
· Sketchwerks**, enable them in that order, then **Preferences ▸ ☰ ▸ Save Preferences**.

## Reporting a bug

Include the add-on and its version (Preferences ▸ Add-ons), your Blender version, and what
you did before it went wrong. A `.blend` that shows it is worth a hundred words.
